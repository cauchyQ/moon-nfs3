# MoonNFS3

An NFSv3 over TCP client for MoonBit. Implementation is in progress.
The library builds on MIT-licensed `kekeshuo/moonxdr` for XDR and RPC wire data.
File operations, connection management and transfer semantics are implemented here.

Apache-2.0. Developed with AI assistance. Protocol references: RFC 1813,
RFC 5531, RFC 4506 and RFC 1833. No libnfs implementation code is bundled.
